T0206 · Defense Evasion · TA07 · observed in 6 incident(s)

Forge or omit build provenance

CI/CD Posture Artifact Security SCM Posture

The attacker ships an artifact without truthful provenance — no SBOM, a
forged SLSA attestation, or a provenance document that names the wrong
source repo, builder, or commit. NIST SSDF PS.3.2 and SLSA Build L2+
exist so consumers can reject unofficial builds; forging or skipping that
paperwork is how a SolarWinds-style implant still looks like a legitimate
vendor release. Distinct from malicious code in the artifact (T0191): this
technique is about lying about *how* the artifact was produced.
