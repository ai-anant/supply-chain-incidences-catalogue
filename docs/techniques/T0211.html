SCIC / Techniques / T0211

T0211 · Execution · TA04 · observed in 1 incident(s)

Abuse registry-adjacent builders as remote execution

Open Source Security CI/CD Posture Artifact Security

The attacker publishes a package whose files are executed not by a
downstream installer, but by a registry-adjacent worker that trusts
package contents: documentation builders (YARD --load on RubyDoc.info),
preview environments, webhook handlers, or similar jobs that treat
.yardopts, setup.py, Makefiles, or lifecycle scripts as commands.
The publisher never needs a victim to gem install / npm install.
Distinct from T0151 (install hooks on the consumer host) and T0166
(poisoning the victim project's own CI). Observed in the 2026 GemStuffer
RubyGems campaign reconstructed by RubyHack, SafeDep, and JFrog.
