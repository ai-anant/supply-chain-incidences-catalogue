OSC&R / Techniques / T0213

T0213 · Execution · TA04 · observed in 1 incident(s)

Orchestrate AI-agent fleet as the intrusion workforce

AI Posture Code Security SCM Posture

The attacker drives multiple AI coding agents (Claude Code, Codex,
OpenClaw forks, Hermes, pi, and similar) in full-auto mode with every
safety approval disabled, tasking and monitoring them over a messaging
channel such as Telegram. The agents run the intrusion lifecycle
unattended — reconnaissance, exploitation, credential theft, wallet
and session collection — and feed results back to the operator, who
never touches a shell on the victim. The agent runtime is the
execution vector; the human retains only tasking and monetization.
Distinct from T0210 (poisoning an existing agent's config or
workspace) and T0152 (a live assistant session as the install
oracle): here the attacker owns the agent fleet outright.
Observed in CloudSEK's analysis of an exposed operator staging host
that revealed an autonomous crypto-theft fleet.
