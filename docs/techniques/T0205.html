SCIC / Techniques / T0205

T0205 · Initial Access · TA03 · observed in 6 incident(s)

Compromise third-party CDN or hosted web asset

Open Source Security Artifact Security Cloud Security

Instead of poisoning a package registry or source repository, the attacker
takes over a widely embedded CDN hostname, tag manager, or hosted JavaScript
asset (domain expiry, registrar hijack, or operator acquisition) and serves
malicious content to every site that loads it. Polyfill.io (2024) is the
reference case: a trusted script URL became a drive-by supply-chain implant
for hundreds of thousands of properties. This catalogue previously had no technique
that named this web-asset supply chain.

Where this idea came from

Public incident / advisory

This catalogue, after Polyfill.io (Sansec) showed CDN/web-asset takeover was unnamed. DEF CON 33: abandoned S3 buckets still referenced by software (Shudrak).
