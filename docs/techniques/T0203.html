OSC&R / Techniques / T0203

T0203 · Reconnaissance · TA01 · identified from research/guidance

Discover localized out-of-band deployments

CI/CD Posture Open Source Security SCM Posture Artifact Security

Attackers look for evidence of an out-of-band or "localized" deployment
path they can hijack — a package.json script that SSHes to production,
a Makefile target that publishes without the main pipeline, a leftover
deploy.sh, or a personal access token used by a developer laptop.
These paths are rarely covered by the same reviews, SBOMs, or admission
controls as the official CI/CD system, which makes them high-value
reconnaissance targets.
