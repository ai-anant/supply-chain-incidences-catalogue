OSC&R / Techniques / T0176

T0176 · Defense Evasion · TA07 · observed in 8 incident(s)

Disable or misconfigure security measures

Cloud Security CI/CD Posture

Attackers disable or misconfigure security controls so that later activity is
not observed or blocked. In software supply chains this is more often a
complete disablement than a subtle misconfiguration: turning off a GitHub
Action required-review check, uninstalling an endpoint agent on a build
runner, skipping a signing gate, or emptying a security-group rule.
Misconfiguration (over-permissive logging, broken audit settings) remains
in scope as the quieter variant of the same Defense Evasion technique.
