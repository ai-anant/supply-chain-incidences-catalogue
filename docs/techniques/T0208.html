SCIC / Techniques / T0208

T0208 · Defense Evasion · TA07 · observed in 5 incident(s)

Compromise code-signing identity

Artifact Security CI/CD Posture Code Security

The attacker signs malware with a stolen or issuer-trusted code-signing
certificate, CI OIDC identity, or package-registry signing key so that
signature verification succeeds. SolarWinds Orion updates were signed as
SolarWinds. Distinct from spoofed git commits (T0195) and from forging
provenance documents (T0206): here the cryptographic identity is real
and compromised.
