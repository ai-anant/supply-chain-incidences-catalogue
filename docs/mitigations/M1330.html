M1330

Implement regular plugin updates

Keep all plugins used in the CI/CD pipeline up-to-date with the latest security patches and updates.
Regularly review the security advisories and release notes of the plugins to identify and address any known vulnerabilities.

Applies to

  • T0133 Vulnerable CICD plugins
