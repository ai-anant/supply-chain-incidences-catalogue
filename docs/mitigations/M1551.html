Poisoned Pipeline / Mitigations / M1551

M1551

Use built-in security controls

Utilize built-in security controls provided by the cloud provider, such as AWS's AWS Shield, AWS WAF, and Azure's Azure Firewall.

Applies to

  • T0155 Cloud workload
