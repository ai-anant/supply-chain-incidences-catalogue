AS40 · 2026-09

Graphalgo spreads to Terraform providers and Go modules

TerraformGo modules

Aikido found Graphalgo-family Go malware in two Terraform providers
(gocommunity-io/dockerd and kreuzwenker/docker, a typosquat of
kreuzwerker/docker with 56 million reported downloads) and two Go
modules (gocommunity.io/orderedbtree, first seen 11 August 2026, and
gogets.dev/btreex, 8 September). This is the first malware Aikido
observed via Terraform providers. The providers stay inert unless
SHA-256(containerName + networkID) equals a fixed digest; that digest
decrypts a ZIP hidden as import-resource.sqlite3, then a detached
go run . executes the second stage. The RAT checks in to Slack
(frontend-devs / qa-announcements; 1,240 messages since 16 July) and
polls an Arbitrum Sepolia contract every 3 seconds. Actor key
302a3005…b526702 is shared with Graphalgo npm samples since April
(modern-events). gogets.dev/btreex hid the payload in a fake .sql
file and activated on a specific price integer; forged commits were
backdated to November 2025 so the Go module proxy showed a false
release date. The operator stood up two non-functional vanity Go
sites (gocommunity.io, gogets.dev) next to attacker GitHub orgs.
Slack check-ins named 18 hostnames (3 Windows, 5 Linux, 10 macOS).
