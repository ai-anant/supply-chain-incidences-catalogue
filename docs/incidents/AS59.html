AS59 · 2026-07

Compromised Injective SDK on npm

npm

On 31 July 2026 Socket reported that the official Injective Protocol
JavaScript SDK on npm had been overwritten with a malicious version.
The poisoned package kept the public API so installs would succeed,
then harvested environment secrets and wallet material from developer
machines and CI. This is a compromised-legitimate-artifact case, not
a typosquat.
