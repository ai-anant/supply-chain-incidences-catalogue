AS46 · 2018-07

eslint-scope and eslint-config-eslint malicious publishes

npmDeveloper workstation

On 12 July 2018 the npm accounts for eslint-scope and eslint-config-eslint
were compromised and malicious versions published. A postinstall script
harvested npm credentials from the developer machine and sent them to
an attacker server. ESLint’s official postmortem is the primary record.
This is the classic “popular linter as credential harvester” case that
the inherited corpus never documented.
