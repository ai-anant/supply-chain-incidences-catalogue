AS35 · 2026-09

PolinRider poisons visanduma/nova-two-factor Packagist via Git

Packagist / ComposerGit / GitHubVS Code / IDE

Socket tracked PolinRider into Packagist through a compromised GitHub
developer account (LaHiRu) on the Visanduma organization, compromised
since mid-June 2026. Malicious code landed in four development versions
of visanduma/nova-two-factor (700k+ cumulative downloads): dev-main,
dev-nova4support, dev-using-inertia, and dev-nova5. No stable malicious
release was identified. Composer (and Go modules) can resolve straight
from Git, so no Packagist publishing token was required. Campaign
methods in this wave: force-pushed history, payloads in config or
.woff2 files, .vscode/tasks.json with "runOn": "folderOpen",
EtherHiding/NullReceiver dead drops, and obfuscated JS in index.php
launched via shell_exec. Primary objective remains cryptocurrency
theft plus credential stealing.
