AS36 · 2026-09

mathmain / mathsbase encrypted npm RAT (equation trigger)

npm

SafeDep and JFrog documented an npm campaign that copies mathjs under
new names (mathmain, mathsbase, math-universe) and ships an AES-256-GCM
loader with no install hooks. The loader stays dormant until a caller
runs lusolve() with a 3×3 Pascal matrix; the LU lower factor JSON is
the password. Decrypted stages are a remote-access implant that reads
a Base/Ethereum Sepolia contract, reports to Slack and Telegram, and
runs operator shell commands from Slack. The loader is in the npm
tarball, not in the public GitHub source. JFrog recovered the trigger
on 21 September 2026; SafeDep reproduced it against mathmain@1.0.0.
Reported download counts were inconsistent with dependents and
jsDelivr traffic. No public caller of the trigger matrix was found.
