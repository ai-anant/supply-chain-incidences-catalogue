AS28 · 2026-08

Keyv / Cacheable ChainDrop worm

npmGitHub ActionsDeveloper workstationAI coding agentsKubernetes

Maintainer Jared Wray's postmortem of the ChainDrop/Shai-Hulud wave on
keyv and cacheable. A leftover full-access GitHub PAT on an infected
developer machine pushed poisoned commits; the projects' own GitHub
Actions plus npm OIDC trusted publishing released them. Poisoned packages
therefore carried genuine SLSA/valid provenance. Provenance proved which
commit was built, not that the commit was authorized. First-wave payload
was a preinstall hook dropping a Bun second stage that harvested
npm/GitHub/AWS/Kubernetes/Vault credentials. About 444 package names /
2,212 versions in roughly four hours.
