TeamPCP DUSTMAKER AI workspace poisoning

npmGitHub ActionsAI coding agentsMCPGit / GitHubVS Code / IDE

Google Threat Intelligence Group's AI Threat Tracker describes DUSTMAKER
(TeamPCP / UNC6780) as the JS/CI successor to SANDCLOCK. It drops hidden
.claude / .cursor / .vscode content, prompt-injects LLM scanners so they
skip the JS underneath, and uses trojanized MCP servers. Packages
published with a valid token pass agent trust checks. A separate Q2 case
used an AI coding chatbot plus markdown playbooks to build credential
harvesting in under six hours after a cloud compromise.
