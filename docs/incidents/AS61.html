AS61 · 2026-03

Fake corepack.org infostealer and proxyware

npmWindows software

After Node.js stopped bundling Corepack, Socket documented corepack.org
impersonating the Node.js package-manager pin tool. The real project
has no official site at that domain and is not distributed as a Windows
installer. “Download Free” redirected to an OpenShield landing page and
dropped vpnsetup_*.exe — an infostealer plus proxyware that enrolled
the machine as a bandwidth-sharing exit node. A second path delivered
OperaGXSetup.exe adware. Node.js contributors flagged the domain in
nodejs/corepack issue 803 (March 2026); it later started serving
executables. Install Corepack only from the npm registry.
