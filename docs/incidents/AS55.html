AS55 · 2026-04

GlassWorm across GitHub, npm, Open VSX, VS Code, Python

Git / GitHubnpmVS Code / IDEPyPIBrowser extensions

OpenSourceMalware reported GlassWorm compromising 430+ GitHub projects
by using four ecosystems at once (GitHub, npm, Open VSX / VS Code,
Python). Multi-ecosystem implants so cleaning one registry does not
clear the campaign. Socket (2 Oct 2026) tied a VS Code theme cluster
to the same loader: the Marketplace build of Cosmic Nebula Themes
reused the previously documented Solana address, AES key, and eval
model. Coca-Cola Christmas and Aurora Borealis Studio Theme shared
the cluster's development artifacts; Marketplace removed the reported
extensions after disclosure.
