AS27 · 2026-09

Hijacked AI coding assistant spreads Shai-Hulud

PyPIGit / GitHubAI coding agentsVS Code / IDEDeveloper workstation

Mandiant's AI Risk and Resilience 2026 report (case study 1) describes an
IR where an attacker hijacked an active AI coding-assistant session. The
assistant recommended attacker-poisoned software; the human accepted; the
same session installed an infostealer via PyPI, stole GitHub OAuth tokens,
and deployed Shai-Hulud across about 100 internal repositories. The actor
then poisoned a package in the company's official namespace, which a
second employee pulled.
