AS19 · 2026-09

Brevo Cloudflare Worker ClickFix

CDN / web assets

On 14 September 2026 an attacker used a long-lived Cloudflare API key that
had been hardcoded in Brevo application source to deploy a Worker that
rewrote HTML and embedded JavaScript at the CDN edge for about five and
a half hours. Origin files were unmodified, so integrity checks on source
missed it. Sansec observed malware on Brevo pages and on 100k+ customer
sites embedding Brevo widgets: a ClickFix overlay plus a WordPress
backdoor plugin aimed at logged-in administrators. Brevo's own
post-mortem confirms the key, the Worker, and the window.

Mapped techniques

supply-chain Brevo Cloudflare account

T0189 · Credential Access · Secrets in configuration files

A Cloudflare API key with full account permissions was stored in
application source code (Brevo post-mortem).

T0112 · Initial Access · Compromised token

The stolen API key created Workers, routes, and DNS records across
Brevo zones without an alert.

T0205 · Initial Access · Compromise third-party CDN or hosted web asset

The Worker rewrote responses at the Cloudflare edge and stripped CSP;
origin was clean.

T0180 · Initial Access · Compromise services / servers

sendibt1.com is a Brevo-operated domain; attacker DNS/SSL on that
zone showed write access to Brevo's CDN naming.

post-supply-chain Customer sites embedding Brevo widgets

T0159 · Execution · Malicious artifact execution

sdk-loader.js and brevo-conversations.js on customer origins loaded
extra attacker script.

T0119 · Execution · Cross-site scripting

Injected script ran in the context of customer sites and Brevo pages.

T0138 · Persistence · Backdoor in code

Logged-in WordPress admins were targeted with a silent plugin install
that persisted as a must-use plugin.

T0201 · Impact · Customers compromised

Sansec estimates 100k+ sites embedding Brevo components were in the
distribution path; visitors saw ClickFix, admins risked a backdoor.

Framework gaps noted

  • Edge/CDN response rewriting (origin untouched) is only partly covered by T0205.
