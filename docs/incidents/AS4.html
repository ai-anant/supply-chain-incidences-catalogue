AS4 · 2021-03

php.net git server Zerodium backdoor

Packagist / ComposerGit / GitHub

On 28 March 2021 two malicious commits landed on git.php.net impersonating
PHP developers. The change would execute attacker-supplied code if the
HTTP User-Agent started with "zerodium". The official php.net news post
said the malicious commits were caught before they reached end-user
releases. PHP paused releases, enabled MFA, and later moved canonical
development to GitHub. The inherited text wrongly dated this to 2023.
