AS39 · 2026-09

sckit worm in MemTensor npm plugin and PyPI MemoryOS

npmPyPI

StepSecurity documented malicious releases of the legitimate MemTensor
AI-memory plugin @memtensor/memos-cloud-openclaw-plugin on 23 September
2026. Versions 0.1.21, 0.1.23, and 0.1.25 added lib/sckit.js and
platform-native .sckit binaries. There was no install/preinstall/
postinstall script: the plugin's own gateway-startup and memory-recall
paths import launchStageZero, spawn a detached sckit binary with
--config64, copy the parent environment (including credentials), and
on recall also pass the user's prompt as SCKIT_EVENT_TEXT. Clean
0.1.22 and 0.1.24 restored the package; malicious contents returned
3 minutes 36 seconds and 3 minutes 28 seconds later. Unpacked size
jumped from ~272 KB to ~43.6 MB. MemTensor issue 173 reports npm
artifacts with no matching git commits or tags, so publishing
credentials were used rather than the source repo. An uncalled
collectStageZero helper maps NPM_TOKEN/NODE_AUTH_TOKEN. PyPI
MemoryOS 2.0.34 is the Python counterpart: a logging-init hook in
configure_logging() reaches the launcher on import, six hashed
payloads, and a hash-pinned CI delivery chain. Binary strings name
recursivePublish and a GitHub Actions template; StepSecurity treats
those as intended propagation, not observed extra publishes.
