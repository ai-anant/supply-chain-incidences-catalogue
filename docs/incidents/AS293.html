AS293 · 2026-08

Exposed operator staging host reveals autonomous AI-agent crypto-theft fleet

AI coding agentsWindows softwareLinux distro / packages

CloudSEK (19 August 2026) enumerated an adversary's exposed open
directory — a staging host serving the operator's full working home
folder (21,442 directories, 142,262 files) to the public internet —
and recovered the tooling, methodology, credentials, and stolen data
behind two parallel campaigns. The operator drives multiple AI coding
agents (Claude Code, Codex, and open-source Hermes and pi agents) in
full-auto mode with every safety approval disabled, tasking and
monitoring them entirely over Telegram; one live bot token leaked
straight into a session transcript, and one bot self-described in
Chinese as a "social-engineering bot". Campaign 1 was internet-wide
opportunistic exploitation (12,048 compromise records across 8,996
unique sites, a fastjson2 deserialization RCE kit, and a
ProjectDiscovery-style recon suite driven from a multi-million-host
FOFA corpus). Campaign 2 was targeted crypto and DeFi theft: clone
sites of a DeFi codebase (the one site running the legitimate
unmodified codebase returned 403 and leaked nothing), a consolidated
wallet export built entirely from those clones, a scripted extraction
of 2,250 real user wallet addresses (EVM and Solana) with derivation
paths from a blockchain compute platform, and providers' live paid
RPC and analytics API keys (Helius, QuickNode, and similar) extracted
from client-side bundles and confirmed working against production.
The host also carried a blockchain-C2 development project, a
WordPress mass-exploitation toolkit, a cryptocurrency miner, and
harvested credentials from a large number of victims. A sister host
brokered LLM API requests during a live intrusion session through a
self-hosted LiteLLM proxy. This is the operator's own agent fleet as
the workforce — not a poisoned agent (AS27, T0210) and not an
injected prompt into a victim's session.
