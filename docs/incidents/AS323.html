AS323 · 2020-12

Operation SignSight trojanized VGCA installers on a government CA's download site

Windows softwareInstaller / update channelCertificates / trust stores

ESET (17 December 2020) found that two software installers on the
Vietnam Government Certification Authority website, ca.gov.vn, had been
modified to carry a backdoor: gca01-client-v2-x32-8.3.msi and
gca01-client-v2-x64-8.3.msi, signed installers for the authority's own
digital-signature client. The implant is PhantomNet (also reported as
SManager, analysed by NTT Security). ESET confirmed the files were
downloaded over HTTPS from ca.gov.vn, so a network man-in-the-middle is
unlikely — the hosted files themselves were replaced. The window ESET
believes is July to 16 August 2020; the site was not serving the
compromised installers by late August. VGCA said it was already aware of
the intrusion and had notified affected users; ESET telemetry found no
distribution outside this site.
