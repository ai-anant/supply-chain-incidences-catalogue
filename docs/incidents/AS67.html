AS67 · 2026-07

mrmustard 0.7.4 PyPI credential stealer via stolen publish token

PyPIGitHub Actions

On 24 July 2026 XanaduAI’s quantum photonics library mrmustard 0.7.4
appeared on PyPI with no matching git tag. An attacker who took over
maintainer ziofil used throwaway GitHub Actions workflows to recon
self-hosted runners (whoami) then POST the repo’s PyPI and Codecov
tokens to webhook.site. With the token they uploaded 0.7.4; only the
tarball’s __init__.py carried a fake _check_tf_compatibility() that
on import stole SSH keys, AWS and Kubernetes configs, skipped CI, and
installed cron, a .pth hook, and a shell-rc persistence. First reported
by Ilyas Makari / Aikido (GitHub issue 656); StepSecurity detonated it.
