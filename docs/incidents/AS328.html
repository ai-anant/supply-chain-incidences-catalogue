Poisoned Pipeline / Incidents / AS328

AS328 · 2026-10

testmetest npm names ship a Miasma-family worm that wipes the home directory if a stolen GitHub token is revoked

npmPyPIRubyGemsGit / GitHubGitLabGitHub ActionsDeveloper workstationAI coding agentsMCPVS Code / IDELinux distro / packagesmacOS softwareWindows software

On 22 October 2026 SafeDep reported an operator publishing npm packages
whose names end in testmetest. Between 19 and 22 October the registry
received 15 such names. Accounts alexjoipamiba and testnewtestme
published four of them. Each name followed the same ladder: a
0.0.0-stage stub, a harmless 1.0.0 decoy, then a malicious patch that
was tagged latest. SafeDep says event-bus-lite-testmetest 0.0.1,
published 10:59 UTC on 22 October by alexjoipamiba, carries the worm.
The other eleven names had already left the registry on 21 October.
SafeDep had found no compromised third-party packages and no victims.
All observed publishes belonged to the operator's own test accounts.

A registry read on 24 October shows event-bus-lite-testmetest and
retry-utils-testmetest unpublished at 20:21 UTC on 22 October, after
further versions of the first name (0.0.2, 0.0.3, 0.0.5, 0.0.6, 0.0.8)
that SafeDep's table did not list. sdk-utils-testmetest and
kvarzo8f3atestmetest now resolve only to a 0.0.0-stage plus a
0.0.1-security version created at 20:36 UTC the same day. Those
tarballs were not fetched. data-pipeline-testmetest was unpublished
at 15:07 UTC on 21 October, matching SafeDep.

The packages have no install scripts. npm runs node-gyp rebuild when
binding.gyp is present, and the sources field is what starts the
loader. index.js decrypts a Bun bootstrap and a 320 KB payload file,
writes the payload under /tmp, runs it with bun, and deletes it.

SafeDep's decode of the payload: it exits on Russian and other CIS
locales and on known sandboxes. In GitHub Actions it tries to kill
StepSecurity Harden-Runner through the Docker socket and to point
stepsecurity.io at localhost, and it exits if that fails. It collects
SSH keys, npm, PyPI and Git credentials, .env files, browser logins,
Claude, Codex, Gemini and Copilot credentials, cloud, Vault and
Kubernetes secrets, and GitHub Actions secrets from the runner worker
process. It commits the encrypted haul to a new public repository on
the victim's GitHub account. The commit message starts with
AutoSyncComplete: and carries the victim's GitHub token, encrypted.
Other infections search for those commits. A fallback endpoint is
aiarmor.website.

It adds the loader to the victim's npm packages and publishes a patch,
and it republishes to PyPI, RubyGems and JFrog. It commits a fake
CodeQL workflow, AI-agent files (.claude/settings.json,
.cursor/mcp.json, CLAUDE.md, AGENTS.md, .vscode/tasks.json) and a
Windows loader at .github/init.ps1 into GitHub and GitLab repositories,
copying the author and message of the latest real commit. It copies
itself over SSH to hosts in known_hosts.

Persistence is two user services, net-health-checker and pkg-runtime,
including a macOS LaunchAgent. net-health-checker polls the stolen
GitHub token every 45 seconds for 48 hours and, on 401 or 403, deletes
the home directory. pkg-runtime hourly searches GitHub commits for
msync-3f7a and runs a Python script from a URL signed by the
attacker's key.

SafeDep does not attribute this build to the June 2026 Miasma
operators. Loader layout, strings and infrastructure differ, and the
token-revocation wiper is the Mini Shai-Hulud behavior. That family
read is not a reason to merge this publish into AS50.

T0216 · Impact · Wipe developer profile if a stolen token is revoked

net-health-checker polls the stolen GitHub token every 45
seconds for 48 hours. On 401 or 403 it deletes the home
directory. Revocation is what starts the wipe.

Framework gaps noted

  • The install trigger is a binding.gyp sources field that node-gyp expands, not an npm lifecycle script. That is not T0151, and it is not T0118 (command injection into a victim application).
  • GitHub Actions secrets taken from the runner worker process are not T0140 (environment variables) or T0183 (tokens in CI logs and variable groups).
  • The hourly command channel is a search for GitHub commits marked msync-3f7a, plus a signed URL. That is not T0156 (webhooks). The aiarmor.website fallback is the same gap.
  • Copying the payload over SSH to hosts in known_hosts has no technique.
  • Republish to JFrog is in the payload. There is no platform id for that registry.
  • SafeDep does not attribute the operator. Do not merge with AS50. No confirmed downstream install. No OSV or GHSA id in the write-up.
  • Later versions of event-bus-lite-testmetest that appear only in the registry time record were not in SafeDep's table and were not fetched here.
