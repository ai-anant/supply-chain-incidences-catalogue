OSC&R / Incidents / AS76

AS76 · 2026-07

Typosquatted AI-tool npm packages under a real-identity publisher

npm

OpenSourceMalware documented a July 2026 npm campaign of typosquatted
AI-tool packages that collected git, SSH, and cloud identity data in
install scripts and never needed to run at import time. Unlike typical
throwaway-account floods, packages were published under a coherent real
identity and iterated across at least five packages, including
@aspect-security/argon2 — a broken-shell package that only had to be
installed. Beacon traffic was dressed as telemetry. OSM’s point: install
time is code execution, and runtime scanners miss packages with no
runtime.
