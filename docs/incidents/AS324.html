Poisoned Pipeline / Incidents / AS324

AS324 · 2020-12

Operation StealthyTrident compromised Able Desktop's update server

Windows softwareInstaller / update channel

ESET (10 December 2020) documented Operation StealthyTrident: the update
server for Able Desktop, a Mongolian corporate application, was
compromised and used to deliver HyperBro, Tmanger and a ShadowPad
variant to the software's users. Trojanized installers and the product's
own update mechanism were both used. ESET attributes the activity to
LuckyMouse (also tracked as TA428), a China-linked actor, and notes
competing hypotheses for how the ShadowPad C2 access was shared. Able
Soft told ESET the trojanized installers and updates had not been used
since the incident was reported, and that it halted automatic updates as
a precaution; the last occurrence ESET saw was July 2020.
