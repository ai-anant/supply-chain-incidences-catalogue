AS64 · 2019-03

electron-native-notify planted in Agama / Komodo wallet

npm

In March 2019 the npm security team, with Komodo, stopped a plot to
steal Agama wallet seeds. GitHub user sawlysawly added
electron-native-notify ^1.1.5 to KomodoPlatform/EasyDEX-GUI on 8 March.
Version 1.1.6 (23 March) was the first with a malicious payload; Agama
v0.3.5 shipped it on 13 April. After launch the wallet fetched a second
stage from updatecheck.herokuapp and exfiltrated the seed. Classic
“useful package, wait until adopted, then flip the next version.”
npm removed the package and wired npm audit.
