DPRK VS Code dictionary and tasks.json droppers

VS Code / IDEGit / GitHub

OpenSourceMalware documented Contagious Interview / Lazarus waves that
hide multi-stage droppers in VS Code configuration rather than in an
npm tarball: spell-check dictionary files (Dec 2025) and tasks.json
automation (Nov 2025, Jan 2026 “Fake Font”). Opening the repo in VS Code
is enough for the task or dictionary hook to run. A 72-hour window in
January 2026 hit at least 21 small OSS maintainers via malicious tasks.
