Poisoned Pipeline / Incidents / AS326

AS326 · 2020-06

GoldenSpy backdoor shipped inside bank-mandated tax software

Windows softwareInstaller / update channel

Trustwave SpiderLabs documented GoldenSpy (also tracked as S0493): a
backdoor embedded in a tax-invoicing package that a Chinese bank
required its foreign corporate clients to install in order to pay
Chinese taxes. The software installed a remote-access implant alongside
the legitimate function, and a second component was later pushed to
already-installed copies. The delivery mechanism is the relationship
rather than a compromised repository: the customer installs the product
because a business counterparty requires it, and the supplier of that
software is the bank or its vendor.

Mapped techniques

  • T0197 Use code from untrusted source
  • T0109 Publish malicious artifact

supply-chain Bank-mandated tax software

T0197 · Initial Access · Use code from untrusted source

The installer is supplied by a business partner as a condition
of doing business, so the normal vendor-selection control never
applies.

T0109 · Resource Development · Publish malicious artifact

A backdoor shipped inside the package from the outset, with a
follow-on component pushed to existing installs.

Framework gaps noted

  • The corpus has no technique for coerced installation by a business counterparty. T0197 is the nearest fit and understates the pressure.
