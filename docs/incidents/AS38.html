AS38 · 2026-08

tw-pkgprobe-7731 npm campaign targeted Twilio developers

npm

ReversingLabs found tw-pkgprobe-7731, an npm package with no Twilio
affiliation, published in 11 versions on 14 August 2026 from account
twdepprobe7731. Comments called it an authorized Twilio HackerOne
probe that ran only in Twilio's serverless packager sandbox. Version
1.0.0 exited unless it detected a Twilio developer environment, then
sent environment variables, mounts, temp folders, cwd, and hostname
over a webhook. Versions 1.0.1–1.0.3 looked for folders named after
34-character Twilio SIDs and, on a match, injected a PoC package into
node_modules. Version 1.0.4 added ACCOUNT_SID and AUTH_TOKEN
exfiltration. Later versions dropped that payload; the last two
probed Twilio-related hosts and fetched AWS IMDS metadata without
using it. The name and publisher did not match Twilio's HackerOne
PoC rules. npm removed the package about an hour after publication.
RL judged the operator unsophisticated (no obfuscation, no
typosquat, no attempt to look like a real maintainer).
