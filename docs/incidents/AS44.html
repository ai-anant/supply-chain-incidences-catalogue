AS44 · 2026-08

StubMaker RubyGems (and npm) Windows infostealer

RubyGemsnpmGit / GitHubLinux distro / packagesmacOS softwareWindows software

On 15 August 2026 OpenSourceMalware found newly published RubyGems
typosquats whose extconf.rb fakes a native-extension build (empty make
targets / make_stub) while downloading a 22 MB Rust loader from GitHub
Releases. The loader carries an 11 MB Go infostealer in its own data
section — no second-stage URL after the first fetch. Targets browser
passwords (including Chromium ABE), wallets, seed phrases, Telegram.
A parallel npm cluster shared IOCs (StubMaker). Hundreds of downloads
before takedown.
