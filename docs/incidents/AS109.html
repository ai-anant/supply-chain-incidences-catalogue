OSC&R / Incidents / AS109

AS109 · 2022-12

PyTorch-nightly torchtriton dependency confusion

PyPI

Between 25 and 30 December 2022, Linux pip installs of PyTorch-nightly
pulled a malicious torchtriton from PyPI instead of the namesake package
on PyTorch’s own index, because PyPI takes precedence. The extra binary
stole environment variables and files from the home directory. Stable
PyTorch packages were not affected. PyTorch’s own advisory is the
primary record; they replaced the dependency with pytorch-triton and
registered a dummy on PyPI. Original OSC&R mapped this as T0113
(compromised user account); it is T0120.
