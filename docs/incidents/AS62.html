AS62 · 2018-06

Operation ShadowHammer (ASUS Live Update)

Windows softwareInstaller / update channel

Between June and November 2018 attackers replaced ASUS Live Update
packages on the official liveupdate01[s].asus.com servers with
backdoored builds signed with legitimate ASUSTeK certificates. Kaspersky
(Securelist, March 2019) reported more than 57,000 of its customers had
installed a backdoored updater; the real target set was a hardcoded list
of 600+ MAC addresses. Related to the 2017 ShadowPad / BARIUM / Winnti
cluster (see also AS5 CCleaner). Surgical supply-chain via a vendor
update channel, not a public language registry.
