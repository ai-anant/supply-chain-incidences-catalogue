AS117 · 2026-09

Miri writes env secrets into target/ readable from PR caches

GitHub Actionscrates.io

Rust Security Response Team (21 Sep 2026): cargo miri stored all
environment variables under target/. Combined with GitHub Actions cache
(PRs can read caches written on main), a later PR can recover CI secrets
from the cache. Not a registry hijack — a tool+platform pairing. Short
term fix: Miri only preserves CARGO_* (except tokens) and OUT_DIR.
Nightly 2026-09-22.
