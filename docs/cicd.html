C01 Supply chain compromise on CI/CD

A library, action, tool, or image the pipeline trusts is itself malicious.

  • AS2 3CX Desktop
    3CX's desktop build shipped malware after the Trading Technologies supply chain reached a build machine.
  • AS3 Codecov Breach
    The Codecov bash uploader used inside customer CI was modified to print environment variables.
  • AS12 tj-actions/changed-files GitHub Action
    tj-actions/changed-files and the related reviewdog action printed CI secrets into logs.
  • AS13 Ultralytics PyPI compromise
    A compromised GitHub Actions workflow published the malicious Ultralytics releases.
  • AS16 TanStack Mini Shai-Hulud (CVE-2026-45321)
    TanStack traced the publish to pull_request_target plus Actions cache poisoning.
  • AS17 Team PCP CI/CD secrets campaign
    TeamPCP poisoned CI actions and collected runner secrets across GitHub, GitLab, Azure, Jenkins, Bitbucket, and CircleCI.
  • AS48 Shai-Hulud first wave (@ctrl/tinycolor)
    Shai-Hulud ran TruffleHog on the host, planted an Actions workflow, and republished with stolen npm tokens.
  • AS49 Sha1-Hulud: The Second Coming
    The second Shai-Hulud wave repeated the CI secret harvest and republish.
  • AS74 Nx s1ngularity (stolen npm token via Actions injection)
    pull_request_target plus a workflow_dispatch publish job stole NPM_TOKEN and released nx.
  • AS118 codfish/semantic-release-action tag hijack (Miasma)
    Floating tags on codfish/semantic-release-action were moved onto malicious commits.
  • AS197 actions-cool GitHub Action tags still serve Mini Shai-Hulud after re-enablement
    actions-cool tags were moved onto unsigned commits that still ran the real action afterwards.

C02 Valid account of the git host
