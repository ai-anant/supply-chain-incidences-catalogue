AS51 · 2026-07

jscrambler@8.14.0 preinstall native binaries

npm

Socket detected a compromised jscrambler 8.14.0 six minutes after
publication on 11 July 2026 (~15.8k weekly downloads). An undocumented
preinstall hook runs dist/setup.js and executes a platform-specific
native binary (Linux, macOS, Windows) from an obfuscated CSI container.
Those files do not exist in 8.13.0. Install is enough; no import or CLI
required. High risk for CI that uses Jscrambler on production builds.
