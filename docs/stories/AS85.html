Baileys npm forks farming WhatsApp Channel follows

npm

WhatsApp library so that a developer’s own WhatsApp account follows
attacker channels on install/use, inflating follower counts and
injecting advertising. Abuse of a real messaging API from a lookalike
dependency, not a classic infostealer.
