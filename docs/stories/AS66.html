AS66 · 2026-07

@joyfill/components and @joyfill/layouts obfuscated RAT

npm

On 28 July 2026 malicious 2773-beta versions of @joyfill/components and
@joyfill/layouts shipped an obfuscated loader in the published dist
bundles only — not in GitHub source. The code runs on import, so
npm install --ignore-scripts does not stop it. It resolves C2 via Tron /
Aptos / BNB Smart Chain transactions, opens a Socket.IO RAT, and stages
a Python credential stealer. StepSecurity detonated the versions under
Harden-Runner.
