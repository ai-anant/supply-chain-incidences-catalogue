hackerbot-claw autonomous GitHub Actions exploitation

GitHub ActionsGit / GitHubAI coding agents

StepSecurity documented hackerbot-claw, an account describing itself as
an autonomous security-research agent on Claude Opus, scanning public
repos for exploitable GitHub Actions and opening PRs. Hits included
avelino/awesome-go (poisoned Go script / token theft), Microsoft,
Datadog, CNCF projects, ambient-code/platform (prompt injection into
project instructions), and aquasecurity/trivy (stolen PAT later used
toward the Trivy VS Code extension on Open VSX). Common tell: outbound
curl to hackmoltrepeat.com from the CI runner. No human weekend
operator — continuous bot. StepSecurity, with independent verification
by Thierry Abaléa (Shipfox).
