AS70 · 2026-06

@mastra scope poisoned via typosquat easy-day-js

npm

Between 01:12 and 02:36 UTC on 17 June 2026 an attacker republished more
than 140 packages in the @mastra npm scope (@mastra/core ~918k weekly
downloads, mastra, create-mastra) after taking a dormant maintainer
account. Package source was untouched; each manifest gained one new
dependency, the dayjs typosquat easy-day-js. That package’s setup.cjs
postinstall pulled a second-stage backdoor (Windows/macOS/Linux) that
stole browser history and data from 166 crypto-wallet and security
extensions (password managers, MFA, Zapier) and used a DGA fallback C2.
Same playbook as the March 2026 axios compromise (AS22). OpenSourceMalware
analysis.
