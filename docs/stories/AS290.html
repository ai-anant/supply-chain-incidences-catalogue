AS290 · 2026-08

RevStealer trojanized Electron apps via fake Claude desktop and cheat sites

Git / GitHubWindows softwareAI coding agents

Morphisec Threat Labs documented RevStealer, a Windows infostealer
delivered inside trojanized Electron desktop applications distributed
through GitHub repositories and game-cheat-themed sites. The notable
lure is a fake "Claude Opus 5 Free Desktop" project impersonating
Anthropic and advertising free access to a paid AI model. The theft
itself is ordinary — browser databases, session cookies,
cryptocurrency wallets, password-manager artifacts, and VPN
configurations — but every stage is engineered around the assumption
that something is watching: exfiltration is in encrypted typed
records and the stealer deletes itself after the haul.

  • T0197 Use code from untrusted source
  • T0159 Malicious artifact execution
