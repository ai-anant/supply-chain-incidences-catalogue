OSC&R / Incidents / AS57

AS57 · 2026-09

Eleven NuGet packages posing as game cheats

NuGet

On 15 September 2026 Socket published eleven malicious NuGet packages
posing as game-cheat / trainer tools (Fortnite, Valorant, Roblox, GTA,
CS2, Minecraft and similar). Combined they had been downloaded more than
1.8 million times. Several used a .NET AssemblyResolve handler so the
payload only ran when a missing dependency was requested; others dropped
a second-stage executable from a Discord CDN URL. Payloads included
infostealers, a clipper, and a reverse shell. Not a hijack of a trusted
library — brandjacking of game titles on a public registry.
