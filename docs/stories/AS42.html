AS42 · 2025-11

IndonesianFoods npm worm (86k+ packages)

npm

OpenSourceMalware identified an npm worm that published at least 86,583
packages across 60 user accounts, more than doubling the then-known
malicious-package count. Accounts were created for the campaign rather
than hijacked. The payload auto-publishes further packages (auto.js /
publishScript.js) and pollutes search/infrastructure; it is a volume
worm, not a credential stealer. Named for the internal Indonesian-food
dictionary. Package list is in 6mile/Indonesian-Foods-Worm.
