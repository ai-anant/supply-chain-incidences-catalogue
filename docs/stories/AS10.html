AS10 · 2021-02

Dependency confusion (Alex Birsan)

npmPyPIRubyGems

Researcher Alex Birsan showed that public package registries (npm, PyPI,
RubyGems) will often prefer a higher-version public package over an
internal package of the same name. By publishing placeholder packages
matching internal names discovered in public artifacts, he executed code
inside dozens of large companies. The technique already exists as T0120;
this story records the campaign that made it famous, which OSC&R never
documented as an incident.
