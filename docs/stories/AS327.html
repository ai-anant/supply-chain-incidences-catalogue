AS327 · 2020-11

WIZVERA VeraPort plugin installed malware signed with stolen certificates

Windows softwareCertificates / trust stores

ESET (December 2020) reported that the WIZVERA VeraPort browser plugin,
a download-verification component used by South Korean banking and
government websites, was compromised to install malware on visitors'
machines. The plugin fetched a payload that was signed with
certificates stolen from legitimate software publishers, so signature
checks on the installed file passed. The operation targeted users of
trusted government and financial sites; the watering hole was the
plugin's own distribution path. VeraPort is required by many Korean
banking sites, which is why its install base was broad.

Mapped techniques

  • T0208 Compromise code-signing identity
  • T0154 Malicious IDE extension

The delivered binaries were signed with certificates belonging
