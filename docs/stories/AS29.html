AS29 · 2026-08

Unclaimed packages in official llms.txt files

npmPyPIAI coding agents

Alon Hertz (Evervault) scanned thousands of official llms.txt instruction
files. Many embed pip/npm install lines whose package names were never
registered. Registering a handful with a beacon produced a callback from
inside a Fortune 500 in under four minutes. Agents given only a vendor
name fetched llms.txt themselves and installed the unclaimed package.
This is dependency confusion against first-party instruction files, not
against a lockfile.
