WEL1DROPPER / NUL1DROPPER npm slopsquatting

npmCDN / web assets

In 48 hours a threat actor published 700+ npm packages with AI-slop /
random typosquat names (OpenSourceMalware: WEL1DROPPER, also Flooding
Dropper / NUL1DROPPER). No preinstall/postinstall. The README tells
developers to require() the library; that import loads _helpers.js and
starts a cross-platform RAT/infostealer. Primary C2 is three Cloudflare
Workers; fallback reconstructs the payload from DNS TXT under wel1.ru.
Example package checkout-mobile-bnpl@35.6.9.
