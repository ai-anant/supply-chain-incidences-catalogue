AS26 · 2026-09

PhantomRaven hidden HTTP npm dependencies

npm

CrowdStrike described PhantomRaven, an LLM-generated npm info-stealer.
The typosquat package looks like Hello-world; the malware is an HTTP
remote dependency that npm fetches at install and that the npm web UI
does not show. A preinstall hook then runs and harvests GitHub Actions,
GitLab, Jenkins, and CircleCI environment variables. PyPI's similar-name
policy stopped a Python twin; npm did not.
