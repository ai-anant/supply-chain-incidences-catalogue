AS292 · 2026-09

Microsoft counterfeit-installer campaign — same-named archives regenerate server-side per download

Windows softwareCDN / web assetsInstaller / update channel

Microsoft Defender Experts documented (1 September 2026) an active
campaign of counterfeit software-download websites impersonating
trusted vendors — Razer, Microsoft Edge, Kaspersky, Baidu Netdisk,
Calibre, and others — that distribute malicious installer archives,
primarily affecting China-based operations of multinational
organizations and Chinese-speaking users. Microsoft assesses with
moderate confidence that the activity is consistent with the publicly
reported Silver Fox (Yinhu) fake-software campaign. The defining
delivery characteristic: archive families (app_setup.*, zinst.*,
zintall.*, intsoft.*, innstll.*) keep the same filename while the
contents change on every download — server-side payload regeneration
(two content-distinct copies of app_setup.6653004.zip observed written
within roughly 69 seconds) — which defeats URL-reputation and static
hash blocklists. A wrapped installer drops a randomized-path stage-one
payload (stable SHA-256 676a2a7b94ca… under many names), masqueraded
with fabricated version metadata including an unfilled build-template
"TODO: <Product name>" placeholder; a repurposed Indigo Rose TrueUpdate
client runtime fetches further payloads from attacker-controlled
Alibaba Cloud OSS over TLS. Same fake-installer class as AS88/AS61
(brandjacked download pages), not a registry hijack.

supply-chain counterfeit download-site distribution

T0136 · Initial Access · Brandjacking

High-fidelity clones of vendor sites on .com.cn/.hl.cn
look-alike domains with prominent "Download now" buttons.

T0110 · Resource Development · Advertise malicious artifact

The spoofed download pages advertise the impersonated vendors'
popular products.

T0207 · Defense Evasion · Skip or forge artifact integrity verification

Hashes change on every download while the filename stays
constant; static hash blocklists cannot key on the payload.

post-supply-chain Windows victims executing the installers

T0159 · Execution · Malicious artifact execution

The wrapped installer launches the stage-one payload from a
randomized path under C:\Users\Public or Program Files (x86).

T0148 · Persistence · Scheduled TaskJob on self hosted runner

The persistent payload (c6100166e2d3…) is launched repeatedly by
the Task Scheduler service and disables Windows Update services
(wuauserv / UsoSvc / WaaSMedicSvc).

T0176 · Defense Evasion · Disable or misconfigure security measures

Registry keys set for Defender exclusions and Windows Update
policy; vssadmin delete shadows /all /quiet removes recovery.

T0184 · Credential Access · Dumping credentials from files

Attempted SMB remote file access to additional hosts; implants
communicate with attacker-controlled infrastructure.

Framework gaps noted

  • Server-side per-download payload regeneration has no dedicated technique; T0212 is the closest existing technique (routing) and this story records the behaviour explicitly instead of force-mapping it.
