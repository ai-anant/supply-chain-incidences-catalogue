AS21 · 2026-09

Deep-Live-Cam malicious git dependency

PyPIGit / GitHubmacOS softwareWindows software

On 8 September 2026 a commit on Deep-Live-Cam (96k GitHub stars) rewrote
requirements.txt to pull several packages from source URLs and added
linerequests @ git+https://github.com/pypls/requests.git — a lookalike of
the real Requests project. setup.py hid a loader past 434 spaces; it
fetched a clipboard-hijacking crypto stealer via a Telegraph page and
installed login persistence on Windows and macOS. The maintainer reported
unusual account access despite 2FA. SafeDep traced the chain; the
malicious revision sat on main for about 9 hours 39 minutes.
