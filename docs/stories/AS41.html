AS41 · 2023-01

DPRK Contagious Interview (BeaverTail / npm + git)

npmPyPIGit / GitHubVS Code / IDE

OpenSourceMalware’s 2026 analysis of Lazarus Group’s Contagious Interview
campaign (tracked since 2023): fake recruiters on LinkedIn, Fiverr and
Upwork send developers a “coding test” that is malware. Delivery includes
npm packages (e.g. tailwindcss-forms-kit), git repos, and PyPI. OSM was
tracking 373 npm packages, 405 git repos, 988 threats and 4285 IOCs for
this cluster. Later waves hid loaders in VS Code tasks and fake fonts.
