@velora-dex/sdk 9.4.1 build-pipeline backdoor

npm

OpenSourceMalware found only @velora-dex/sdk 9.4.1 (Velora / formerly
ParaSwap) carrying a base64 child_process.exec in dist/index.js that
curls http://89.36.224.5/troubleshoot/mac/install.sh and runs it under
nohup. Dev tags 9.4.1-dev.1/2 and every other 9.x release were clean,
which OSM reads as a surgical build/release compromise, not a git
takeover. Payload runs on import. npm removed 9.4.1 after GitHub issue
233; 9.4.2 is clean.
