AS1 · 2018-04

Webmin 1.890–1.920 build-server backdoor

Linux distro / packagesDeveloper workstation

In April 2018 an attacker exploited the Webmin development build server and
injected a concealed remote-command backdoor into password_change.cgi. The
change was taken from the local build tree, not from a controlled SCM, so
source review of git would not have seen it. Versions 1.890 shipped an
immediately exploitable root RCE; 1.900–1.920 still contained similar code
that became exploitable if “allow changing of expired passwords” was on.
In September 2018 the old build server was replaced, but the modified
directory was copied from backups and the backdoor returned. This was
deliberate, not an accidental bug. Tracked as CVE-2019-15107 / CVE-2019-15231.
